# Modifications to the upstream project

This educational derivative changes the upstream application as follows:

- migrated the frontend from Create React App to React 19 and Vite 8;
- replaced the original interface and added responsive styling;
- added JSON request headers and same-origin `/api` routing;
- added a database-aware backend health endpoint;
- updated compatible Python dependency pins;
- replaced legacy container images and root runtime defaults;
- created new Docker Compose and Kubernetes implementations;
- removed committed TLS private keys and example production credentials;
- replaced the original documentation with Russian-language training materials.

The original project and license are identified in `NOTICE` and `LICENSE`.
